# Portfólio · Carlos Eduardo

Portfólio pessoal em HTML, CSS e JavaScript puro, sem dependências de build.

## Visualizar

Abra `Portifólio/index.html` no navegador ou use o Live Server do VS Code na pasta `Portifólio`.

## Organização

- `Portifólio/index.html`: conteúdo, metadados e ícones SVG locais.
- `Portifólio/css/style.css`: tokens da identidade visual e componentes.
- `Portifólio/css/responsivo.css`: adaptações para desktop, tablet e mobile.
- `Portifólio/js/menu_mobile.js`: menu, navegação ativa, entradas ao rolar, cópia de e-mail e formulário.
- `Portifólio/images/`: fotografia WebP otimizada e recursos originais preservados.

## Contato

O formulário valida os campos e prepara um link `mailto:` com nome, e-mail, WhatsApp opcional, assunto e mensagem. É necessário um aplicativo de e-mail configurado para revisar e enviar. O site não possui servidor de envio e não afirma que a mensagem foi enviada. Os links diretos de e-mail e WhatsApp também estão disponíveis.

A tipografia usa Plus Jakarta Sans pelo Google Fonts, com fontes de sistema como alternativa. O conteúdo e a navegação continuam acessíveis sem JavaScript. Animações respeitam a preferência por movimento reduzido.

## Verificação local

As capturas e o relatório de revisão ficam em `.preview/`, fora da pasta do site. O script de revisão usa Chrome instalado no Windows e verifica larguras de 320 a 1920 pixels, menu por teclado, âncoras, rótulos, carregamento de imagens, campos obrigatórios, codificação do e-mail e movimento reduzido. Não envia mensagens nem altera os contatos.

## AnjosFlow no portfólio

O card usa uma captura real do dashboard, otimizada em JPEG, e mantém os links do [repositório](https://github.com/horaanjos/AnjosFlow) e da [apresentação pública](https://anjosflow-horaanjos.netlify.app). A apresentação funciona em modo de portfólio; API e banco são locais.

As novas competências foram verificadas no [README do AnjosFlow](https://github.com/horaanjos/AnjosFlow/blob/master/README.md), nas [dependências Java](https://github.com/horaanjos/AnjosFlow/blob/master/backend/pom.xml), nas [dependências web](https://github.com/horaanjos/AnjosFlow/blob/master/frontend/package.json), no [Docker Compose](https://github.com/horaanjos/AnjosFlow/blob/master/compose.yaml) e na [documentação da API](https://github.com/horaanjos/AnjosFlow/blob/master/docs/api.md).

A inclusão de React, Tailwind CSS e outras ferramentas nas competências descreve o uso no AnjosFlow. Este portfólio continua em HTML, CSS e JavaScript puro.
